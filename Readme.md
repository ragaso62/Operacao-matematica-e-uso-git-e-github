# Operação Matemática e Uso de Git e GitHub

## 📖 Sobre o Projeto

Este projeto foi desenvolvido com o objetivo de praticar conceitos básicos de programação através da implementação de operações matemáticas, ao mesmo tempo em que serviu como ambiente de aprendizado para o uso das principais ferramentas de versionamento de código: Git e GitHub.

Durante o desenvolvimento, foram realizados diversos testes envolvendo criação de repositórios, commits, sincronização com repositórios remotos e organização de versões do projeto, proporcionando uma experiência prática com o fluxo de trabalho utilizado por desenvolvedores profissionais.

## 🎯 Objetivos

- Praticar lógica de programação e operações matemáticas.
- Aprender os fundamentos do Git.
- Utilizar o GitHub para armazenamento e gerenciamento do código.
- Compreender o fluxo básico de versionamento de software.
- Desenvolver familiaridade com comandos essenciais utilizados no dia a dia do desenvolvimento.

## 🛠️ Tecnologias Utilizadas

- Linguagem de Programação
- Git
- GitHub

## 📚 Conhecimentos Praticados

Durante este projeto foram utilizados conceitos como:

- Inicialização de repositórios Git.
- Criação de commits.
- Envio de alterações para o GitHub.
- Atualização de repositórios remotos.
- Controle de versões.
- Organização e acompanhamento da evolução do código.

## 🚀 Aprendizados

Este projeto foi importante para consolidar os primeiros contatos com ferramentas de versionamento, fundamentais no desenvolvimento de software moderno. Além da implementação das operações matemáticas, a prática constante com Git e GitHub permitiu compreender melhor como desenvolvedores trabalham de forma organizada, segura e colaborativa em projetos de diferentes tamanhos.
